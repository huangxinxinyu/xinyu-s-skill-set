# 综合个人画像

交付可双击打开、离线交互的完整 HTML 网页，帮助用户查看和修正自己的兴趣、工作方式、偏好与目标。中文为默认语言；遵循用户指定的语言和侧重点。

## 整理画像

使用当前对话中用户明确提供的信息，以及用户指定的资料。项目文档描述的是项目，不自动证明用户的身份、经历或兴趣。称呼未知时使用“我的画像”。不要扫描整个用户目录或自行读取账号、邮件等私人数据。

每个条目标记“已知”或“待确认”，附上具体原话、资料位置或推断原因：

- 已知：用户明确自述或指定资料明确支持的事实。对话中偏好需保留适用范围，不能把一次要求写成永久性格。
- 待确认：有具体依据的有限推断，正文明确写“可能”并说明需要确认什么。没有依据的未知信息写成补充问题，不生成画像结论。

少量事实也能生成可用的初始网页。必要时只问一个会改变画像方向的问题；继续交付，并用补充问题引导完善。不要编造履历、人格评分或心理诊断，不从目录名猜真实姓名。

## 生成网页

1. 读取 [画像数据格式](references/profile-schema.md)，创建输出目录内的 `profile.json`。先检查是否已有用户画像；更新时保留用户修订与依据，冲突标记待确认，不悄悄覆盖。浏览器暂存的修改不可从原始 JSON 获取，请用户导出 JSON 后作为输入。
2. 用技能目录下的渲染器生成单文件网页：

   ```bash
   python3 <skill-dir>/scripts/render_profile.py --input <output-dir>/profile.json --output <output-dir>/index.html
   ```

   输出默认放在当前工作目录的 `output/personal-profile/`。已有文件时先读取并核对，选择新路径或在用户授权更新后使用 `--force`。渲染器仅依赖 Python 标准库，无需安装前端依赖。
3. 在可用的本地浏览器验证：筛选、查看依据、编辑保存、刷新保留修改、JSON 导入导出、完整 HTML 导出后重新打开。没有浏览器时执行渲染和语法检查，并如实说明交互验证范围。
4. 返回可点击的 `index.html` 本地绝对路径，说明双击打开；简述可编辑和导出功能。不要只返回画像正文、代码片段或 localhost 地址。

## 网页行为

复用 `assets/profile.html`：自包含样式与脚本，按兴趣/工作方式/偏好/目标筛选，状态筛选和搜索，依据展开，条目及简介编辑，JSON 导入导出，完整 HTML 导出，浏览器暂存与不可用时提示。无需登录、API key 或联网。所有资料用文本节点展示；保留渲染器对内嵌 JSON 的转义。

浏览器暂存只属于当前浏览器，HTML 导出才是可携带最新修改的交付物。导出的画像可能包含私人信息，是否分享由用户决定。不要自动发布、上传或接入支付；这些属于后续明确请求。
