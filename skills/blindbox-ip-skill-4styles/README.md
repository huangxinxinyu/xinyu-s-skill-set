# 内容配图角色 IP Standard Pack

把你或你的品牌变成一个能长期出镜的内容配图角色。即使不懂 IP 设计，也可以从一段简单描述开始，得到角色形象、价值观、三视图、统一参考图和可反复使用的提示词。

入口：[`SKILL.md`](./SKILL.md) · 画风参考：[`style_refs/`](./style_refs/)

## 你会得到

- **角色价值观**：她相信什么、怎么表达、绝不代表什么；
- **视觉 DNA**：形态、比例、脸、招牌件、HEX 色板与画风；
- **正面图 + 三视图**：锁定角色正面、侧面和背面结构；
- **角色参考板**：以后在其他 Agent 出图时使用的统一参考图；
- **可复用提示词**：角色、画风、动作、场景分开替换；
- **3 张测试图**：验证角色在不同动作和场景中是否稳定；
- **Standard Pack**：所有图片、提示词和说明放在同一个可移动文件夹中。

## 怎么用

把 Skill 交给支持图片生成的 Agent，然后说：

> 帮我生成一个能长期用于内容配图的个人或品牌 IP，并交付 Standard Pack。

你可以任选一种方式开始：

1. **上传 1–5 张参考图**：每张只需说“喜欢”“不喜欢”或“只喜欢配色/比例/质感”；
2. **粘贴已有内容**：给它 1–3 段代表性文章、帖子、账号简介或品牌介绍；
3. **简单说几句**：你是谁、发布什么内容、希望给人什么感觉、角色用在哪里；
4. **直接说“不知道”**：让 Agent 根据内容主题和受众推荐 2–3 个方向。

本人照片、Logo、产品图、品牌色或旧角色也可以上传，并注明哪些元素必须保留。参考图只用于提取偏好，不会照抄其中的角色。

Agent 会先推荐适合的画风，你确认角色方向、画风和正面图后，它再继续完成三视图、角色参考板、提示词与测试图。

## 四种画风

Agent 会根据用途和参考图推荐 1–2 种，但生成图片前必须由你确认。

1. **治愈绘本手绘**：像独立绘本和手绘文创角色，温暖、有颜料与纸张质感；
2. **极简符号卡通**：可以用 Miffy、LINE FRIENDS 的简化逻辑帮助理解，适合头像和贴纸；
3. **盲盒潮玩公仔**：可以理解为泡泡玛特这一类设计师玩具的立体、圆润和商品感；
4. **日常扁平漫画**：可以用 Snoopy、Moomin 漫画的内容表达逻辑帮助理解，适合长期配图。

知名 IP 只帮助理解，不会写进生图提示词。正式风格卡使用同一个原创角色展示四种效果，避免把角色长相误认为画风。

## 以后怎么复用

1. 上传 Pack 里的 `character-reference-board.png`；
2. 粘贴角色的 `identity_lock` 和 `style_lock`；
3. 只替换动作、场景和构图；
4. 对照 Pack 的一致性清单检查新图。

## 说明

使用支持参考图的 Agent，角色一致性目标为 Identity QA 90/100；不支持参考图时，只靠文字提示词无法保证相同效果。不同图片模型的表现会有差异，Pack 会保留生成方式与已知限制。
